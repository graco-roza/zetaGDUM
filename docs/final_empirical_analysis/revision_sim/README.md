# revision_sim: simulations of the MS-GDUM spread-by-position interaction

`REPORT.md` has design, results, negative results and limitations. `00_sim_common.R` shared model/support/contrast helpers; `10_simA.R` Simulation A (known parameters); `11a_simB_truth.R` species pool, guild model and Monte Carlo truth; `11b_simB_fit.R` Simulation B model comparison; `12_tables.R` summaries; `14_projection_test.R` surface-projection test; `13_figure.R` figure. Large surface tables are committed as `.csv.gz`.
