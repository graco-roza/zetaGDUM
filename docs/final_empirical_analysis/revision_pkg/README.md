# revision_pkg: simplified principal package

Package branches (https://github.com/graco-roza/zetaGDUM):
* `experimental/interactions` = commit f7e115f, unchanged: explicit spread-by-position interaction implementation (design, fitting, diagnostics, contrasts, penalty selection, contextual spread, `interaction` component model), tests and documentation. Preserved for future methodological research; not part of the principal interface.
* `principal/additive-msgdum` (from f7e115f): additive framework only. Retained: spread-only MS-GDM, MS-GDUM with linear and nonlinear environmental position, coherent and independent component modelling, within-order Shapley/Owen attribution, order-selection and retention diagnostics. Changes: `ugdm_interaction_design(spread = "constant")` -> `ugdm_position_design()`, `ugdm_fit_interactions()` (without interaction shrinkage) -> `ugdm_fit_position()` (new `spread_only = TRUE` matched comparator), `ugdm_interaction_contrast()` -> `ugdm_position_contrast()`, `ugdm_interaction_diagnostics()` -> `ugdm_position_diagnostics()` (spread and position allocations only), `ugdm_select_interactions()` -> `ugdm_select_penalties()`; removed `ugdm_contextual_diagnostics()`, the `interaction` component model and `interaction_shrink`; `ugdm_site_partitions()` kept. No cross-predictor interaction was introduced. Dependencies unchanged (all still used). Tests: full suite passes (including new tests of the position models, the spread-only comparator and the absence of interaction exports); `R CMD check` (without vignettes) reports no errors.
* `regress_additive_equivalence.R` and `regression_f7e115f_vs_principal.csv`: numerical regression of every retained additive path (original fit, linear/nonlinear position fits with all penalty options, diagnostics, within-order importance, penalty selection, coherent/independent spread-only and additive component fits, predictions, importance and validation) between f7e115f and the principal branch: all identical within 1e-10.
