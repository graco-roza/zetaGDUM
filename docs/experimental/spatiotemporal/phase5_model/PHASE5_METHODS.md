# Phase V methods

## Scope and reproduction

Work from the repository root with the repository version of `zetaGDUM` installed into an R library. Set `R_LIBS` to include that library. The workflow also uses Rcpp, data.table, ggplot2 and scales. The two empirical archives must be prepared with the Phase IV and IV-B download and preprocessing scripts. The analysis reads their raw archives and prepared outputs in place.

```sh
bash docs/experimental/spatiotemporal/phase5_model/scripts/run_all.sh
```

The full simulation defaults to 100 replicates for each main configuration. `ST5_REPS`, `ST5_WORKERS` and `ST5_EMPIRICAL_WORKERS` control the replicate count and worker counts. For a portable serial run, set both worker counts to 1. The incomplete-monitoring example is `scripts/04_example.R`.

## Observation support and responses

`st5_input()` takes a long table with one record per site and time, aligned incidence and/or abundance matrices, and optional aligned environmental columns. A binary availability column is optional. The index contains missing keys for unavailable records. A zero vector on a sampled record represents an observed empty community. Taxon columns represent one harmonized taxon pool across records. Numeric time retains its input unit. Date and POSIX time use elapsed days.

`st5_support()` materializes a distinct set of eligible site combinations for each survey or temporal contrast. Spatial groups use all sampled sites at the survey. Local groups use consecutive observations at each site by default, with all pairs and explicit lag filters available. For a local contrast, the focal sites are the eligible sites under the local pairing rule. Process classification uses **all** jointly observed sites at the two survey dates. Rectangles use intersections of the sampled site sets over their requested dates. Custom static windows and paired equal-order, chronological, non-overlapping windows are supported. The default paired multiyear trajectory compares adjacent non-overlapping windows of the requested order. Time support for an individual analysis is explicit in the resulting row lists.

For a rectangle of \(N=km\) observations, let \(Z_I\) be the number of ubiquitous taxa and \(Z_A\) the sum of the species-wise minima of local relative shares. The two incidence denominators are mean richness and minimum richness. Define \(D_I=1-Z_I/\overline r\), \(D_T=1-Z_I/r_{\min}\), and \(D_N=D_I-D_T\). At \(N=2\) these give the defined Sørensen–Simpson partition. At higher orders they use the native full intersection. A zero richness denominator gives an undefined response. Relative abundance uses \(D_A=1-Z_A\) and a rectangle with any empty assemblage has undefined relative composition. For abundance partitioning the minimum positive share \(b_s\) is the reference. If \(p_s\) denotes occupied fraction, \(H_s\) denotes ubiquity and \(\mu_s\) denotes mean positive share, the terms are \((p_s-H_s)b_s\) and \(p_s(\mu_s-b_s)\). Absent taxa contribute zero. Numerical terms are relative heterogeneity.

Local distances use Sørensen or relative Bray–Curtis. Incidence gains and losses use the same denominator \(2c+g+l\). Shared temporal distance uses the original shared vectors with their original sums. Spatial or joint-window change subtracts the initial normalized dissimilarity from the final one. These changes and temporal distances have different interpretations.

## Counterfactuals and aggregation

Classify each taxon's gains and losses before subsetting spatial combinations for a paired contrast. Each aligned position in a multiyear contrast is classified over the same window-matched panel. The expansion and contraction blocks contain excess gains and losses. The redistribution block contains equal numbers of the remaining gains and losses. The numerical block edits relative shares at persistent occurrences. Phase III enumerates admissible allocations exactly at small cardinalities and samples uniformly at larger cardinalities. Each draw applies to the whole regional contrast and is shared across responses on that call. Explicit seeds reproduce draws. Across response/support calls, coordinates and identical window ordering are needed for identical allocation streams. Regional status is conditional on the sampled panel.

The eight-coalition kernel is used for incidence. The sixteen-coalition kernel closes every abundance counterfactual after editing endpoint relative shares. For abundance input the implementation compares its dummy-numerical incidence accounting to the explicit three-block game before returning incidence model data. It retains an allocation standard deviation only via the draw data internally and returns Monte Carlo SE per combination/process, with zero MC error for exact enumeration. A response is attributed only if all its coalitions are defined for every allocation draw. A temporal endpoint distance can remain defined even if its attribution is unavailable because the initial shared or local vector has zero mass. The pairwise spread and the allocation procedures reuse the previous phase implementations.

The process Shapley sum equals \(F(\mathcal B)-F(\varnothing)\). For temporal distance, the mathematical zero baseline applies on its defined support. Contributions can be signed. Magnitudes in opposite directions are averaged separately before computing shares. Temporal distance directions indicate increased or decreased distance to the initial composition. For spatial and joint-window dissimilarity, negative contributions reduce differentiation. Numerical changes can reflect closure when other taxa change. Redistribution establishes balanced gained and lost occurrences in the sampled panel.

Use all eligible combinations where feasible. Otherwise IID uniform sets are sampled with replacement within each period. A row's primary weight is the reciprocal of its period sample count, with optional positive importance ratios normalized within each period. Local observations instead share equal total weight per site. Model fitting normalizes weights to sum to one after restriction to the model's valid support. Equal combination-row weights are an empirical sensitivity. Distribution summaries of conditional mean predictions ordinarily lose residual gross variation.

All-observation spatial means use each survey's eligible set. Matched change uses within-combination differences on defined common coalition support. The all-minus-matched difference is a descriptive support discrepancy. Cumulative annual change telescopes for fixed identical combination support with identical endpoint definitions. Cumulative contributions for changing matched panels are descriptive sums of conditional contrasts.

## Environmental design

Fit the native `ugdm_design()` scaling and three quadratic I-splines on unique training observation keys. Predictors with fewer than four distinct training values are unsupported. If the joint training basis is unsupported, iteratively remove the least covered variable, using the input order to resolve ties. Fit separate models for a fixed order and response. Compute window means of standardized site conditions, then sum the means to obtain position and average absolute pairwise I-spline differences for spatial spread. Clamp to native boundary knots when evaluating I-splines. Position still uses the actual standardized values. Flag extrapolation using training spline bounds on the raw evaluation observations. Site-local differences use the absolute difference between the endpoint basis vectors. Static spatiotemporal models also include the mean over sites and temporal pairs of within-site I-spline differences. Paired models use initial and signed changes of position and spread. Local models use initial and signed change in position plus temporal differences, omitting spatial spread. Use \(\log(L/L_{ref})\) with default \(L_{ref}=1\) input unit. Nonconstant log-duration and duration change enter as nuisance terms when needed. Interactions are omitted.

Design columns are weighted-centered and scaled in training only. Constant columns are removed and rank is recorded. Signed coefficients use positive ridge penalties without an intercept penalty. The static spatial sensitivity constrains spread coefficients to be nonnegative.

## Models and validation

For a normalized endpoint minimize weighted fractional cross-entropy with ridge penalty. The working logit models a conditional mean in \([0,1]\). The working variance is proportional to \(\mu(1-\mu)\). Degenerate all-zero or all-one endpoints return their constant mean. No binomial trial count is assigned. Change models condition on observed initial dissimilarity. Local and shared distance use baseline zero. For signed contributions \(\phi\), regress \(c_j=\phi_j-\Delta D/d\) with common weights and ridge. The zero sum across response columns is preserved by the common linear estimator. Prediction reconstructs \(\widehat\phi_j=(\widehat D^1-D^0)/d+\widehat c_j\). The endpoint is bounded by construction. Individual predictions beyond \([-1,1]\) are flagged. The signed ridge comparator uses the same design and directly fits process columns. Its predicted endpoint is initial dissimilarity plus their sum, with incompatible totals flagged.

For crossed abundance, fit the endpoint simplex \((1-D_A,D_{occ},D_{num})\) via fractional multinomial cross-entropy with the similarity category as reference. A category with zero total training mass is a structural zero in the working fit. Each component's centered processes are fit separately with common penalty and weights. Total abundance and process predictions are derived by adding the two fitted components. The abundance total from a separate fractional model is a separate prediction.

Spatial outer folds require every held-out combination member in the held-out geographic block and exclude all held-out sites from training. Temporal folds discard rows partially crossing test-block boundaries. Forward folds use strictly earlier complete training windows. Inner validation repeats blocking inside the outer training set, tunes endpoint cross-entropy and centered process squared error separately, and uses a declared 0.01 fallback if inner validation is unavailable. The default penalty candidates are \(10^{-6}\) through \(10^2\) in factors of ten. Spatial and temporal block resampling of held-out scores or importance assesses sensitivity to the blocks, with few available blocks limiting interpretation. There are no independent-combination standard errors or coefficient significance tests.

Environmental importance groups all columns for a predictor or a feature group and computes held-out predictive Shapley values. The empty coalition keeps baseline dissimilarity, elapsed lag and variable duration as relevant. Coalition comparisons use identical folds, weights, rows and the penalties selected for that full-model fold. Report fractional cross-entropy for endpoints, held-out squared error for net change and each process, and pooled joint process loss. Importance can be negative. Exact coalitions are used for up to six groups. Above that, permutation Monte Carlo keeps permutation SE separate from block sensitivity. Pooled improvements are ratios of fold-average losses. Block resampling summaries average foldwise improvements and therefore target a related but distinct quantity.

Regional classifications assigned using complete observed contrasts describe the realized regional metacommunity. A held-out geography fit whose response labels come from the same realized regional classification has a conditional evaluation target. A separate sensitivity recomputes labels within each held-out region and measures the difference for identical eligible combinations. Effects of covariates are associative and partial design-response curves are conditional model summaries.

## Simulations and archives

Simulated histories use 60 sites, 200 taxa and 30 surveys, with spatially structured predictors, AR(1) shocks (0.7), two independent nuisance predictors, and controlled occupancy and numerical mechanisms. The main and environmental-null configurations use 100 independent seeds each. Isolation, opposing mechanisms, stable redistribution, reversal and irregular lags use smaller scenario-specific experiments. A separately seeded and more densely sampled reference estimates a finite model-based predictive importance target. Common-random-number interventions separately disable each real predictor's ecological mechanism to measure changes in realized process contributions. These contrasts and held-out importance are distinct targets.

The incomplete sampling experiment removes 10%, 25% or 50% of communities under random, network entry/exit, missing-period, environmental and geographically clustered designs. Compute complete-panel contrasts and observed support discrepancy separately. Absolute predictions use the declared conditional estimand.

The moth archive is BioTIME study 604. It provides a descriptive analysis only. The three Swedish lake assemblages are from version 1 of the Researchdata.se deposit. Join climate and chemistry by the archived EU lake identifier and calendar year. Raw archive pH, log conductivity, annual air temperature and log precipitation form a compact predeclared predictor set. Annual climate summaries can include months after biological sampling. They describe the survey year and should not be treated as information available before a survey. No temporal disaggregation or imputation is used.
