# revision_sampling
Simulation of how sample size, zeta order and combination sampling constrain estimation and interpretation of TP position and spread in additive MS-GDUM (principal package, no explicit interactions). See `REPORT.md`.
Scripts: `00_sim_common.R` (generators, samplers, metacommunity, truth), `01_support.R` (Figure 6 support machinery as a function of the sampled combinations), `01b_support_diag.R` + `26_binding.R` (diagnostic of binding support criteria), `02_contrasts.R` (contrast helpers copied from Figure 6), `10_meta_rep.R` (site-level metacommunity unit), `11_known_rep.R` (known-parameter unit), `20_run.R` (series S/C/F, resumable), `25_test_null.R`, `30_tables.R`, `40_figures.R`, `run_all.sh`.
Tables (`tables/`): `sim_{meta,known}_{sup,fit,con}.csv` (every replicate; unsupported units are rows of `sup` with `supported = FALSE`), `*_contrast_errors.csv`, `*_availability_{sites,combinations,factorial_k5}.csv`, `*_accuracy_*.csv`, `*_prediction_*.csv`, `*_paired_*.csv`, `*_unsupported_reasons.csv`, `sim_support_binding_criteria.csv`.
Figures (`figures/`): `Fig_S1_availability`, `Fig_S2_success_position_contrast`, `Fig_S3_error_position_contrast`, `Fig_S3b_error_spread_contrast`, `Fig_S4_prediction`, `Fig_S5_sites_vs_combinations`, `Fig_S6_factorial_order5`, `Fig_S7_balanced_minus_random`, each for `metacommunity` and `known_parameter`.
